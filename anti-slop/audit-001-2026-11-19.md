# Antislop Audit #001 (2026-11-19)

**Target:** `AutoCAD-Mac-Ribbon` (`/Users/Ronci/Documents/AutoCAD/AutoCAD-Mac-Ribbon`)
**Verification environment:** Autodesk AutoCAD for Mac 2027 (`26.0s LMS Tech`), live `WKWebView` snapshots across all 10 tabs, light/dark modes, dropdowns, panel trays, live `LOGFILEON` command execution sweep, and official `MenuGroup.cui` / `acad.pgp` verification.
**Mode:** Mode 2 (AFTER). No source files have been modified. Pick the finding numbers you want fixed.

## HIGH Priority (Hard Gate Violations)

1. **[HIGH] [R-26, R-35] 18 dead or unsupported AutoCAD buttons return `Unknown command` or "not supported" in live AutoCAD 2027.**
   - Tested live via `LOGFILEON` and cross-checked against AutoCAD 2027 `MenuGroup.cui`:
     - `Insert -> Block -> Blocks Palette`: sends `_BLOCKSPALETTE` (`Unknown command`); Mac command is `'_content`.
     - `Insert -> Reference -> Adjust`: sends `_ADJUST` (`Unknown command`); Mac command is `_IMAGEADJUST`.
     - `Insert -> Reference -> Xbind`: sends `_XBI` (`Unknown command`); Mac command is `_XBIND`.
     - `Home -> Layers tray`: `Layer Walk` (`_LAYWALK`), `Merge` (`_LAYMRG`), `Delete Layer` (`_LAYDEL`) all fail with `Unknown command` on Mac.
     - `Home -> Clipboard -> Paste Special...`: sends `_PASTESPEC` (Windows OLE only, unsupported on macOS).
     - `Manage -> Applications -> VLISP`: sends `_VLIDE` ("This command is not supported" on macOS).
     - `Output -> Export DWF`: sends `_EXPORTDWF` (not supported on AutoCAD for Mac; `_EXPORT` and `_EXPORTLAYOUT` work).
     - `Collaborate -> Shared Views` (`_SHAREDVIEWS`), `History` (`_DWGHISTORY`) return `Unknown command`; `Traces` sends `_TRACEPALETTESOPEN` (`Unknown command`, typo: real command is `_TRACEPALETTEOPEN`). `Activity Insights` (`'_ACTIVITYINSIGHTSOPEN`) replaces `DWGHISTORY` on AutoCAD 2027 Mac.
     - `Express Tools`: 6 buttons return `Unknown command` (`ARCTEXT`, `BCOUNT`, `TCASE`, `TCIRCLE`, `TCOUNT`, `TXTEXP`). Note: `BURST`, `BLOCKREPLACE`, `NCOPY`, `TXT2MTXT`, `SUPERHATCH`, `BREAKLINE`, `OVERKILL`, `FLATTEN` all work live, and native `_COUNT` / `_COUNTLIST` replaces `BCOUNT`.

2. **[HIGH] [R-26, R-35] Lineweight dropdown never updates its selected label in the Properties panel.**
   - In `ui/ribbon.js` (line 225) and inline `ui/index.html` (line 3299), the check `!cmd?.includes('_LWEIGHT ')` matches every `_-LWEIGHT <val>` item and hits an empty `// Settings dialog only` branch, leaving the combo stuck on `ByLayer`.

3. **[HIGH] [R-26, R-35] Native Ribbon detaches onto modal dialogs (`AcOCUiModalWindow`) and reloads twice on every DWG open.**
   - In `src/RibbonManager.mm` (`isCandidateWindow:`, lines 319-343), the size fallback (`width >= 600 && height >= 450`) matches AutoCAD modal dialogs such as `Customize` (`AcOCUiModalWindow`), ripping the Ribbon off `AcMainWindow` and gluing it across the dialog. Additionally, `kLoadDwgMsg` and `macribbon.lsp` both trigger `switchToWindowsRibbon` with `reloadRibbonContent`, flashing and resetting the Ribbon twice per drawing.

4. **[HIGH] [R-25] Multiple text/background pairings fail WCAG AA (4.5:1) in Dark, Live-Sampled Dark, and Light themes.**
   - Measured with `contrast-check.py`:
     - Live sampled dark (`#4e5868`): panel titles `#9aa7b8` = **2.94:1 FAIL** (fails even large text); muted text `#8c9bae` = **2.54:1 FAIL**.
     - Default dark (`#384555`): panel titles `#9aa7b8` = **4.00:1 FAIL**; muted text `#8c9bae` = **3.45:1 FAIL**.
     - Menu hover (`#ffffff` on `#0096d7`): **3.31:1 FAIL**; tooltip command (`#0096d7` on `#27303d` / `#363d48`): **4.02:1 / 3.31:1 FAIL**.
     - Light theme (`#e5e8ec`): muted text `#656d78` = **4.26:1 FAIL**; accent `#0078d4` on `#f4f6f8` = **4.18:1 FAIL**.

5. **[HIGH] [R-34] Light theme breaks icon visibility because 236 inline SVGs hardcode dark-theme neon hex colors.**
   - Verified in live `ribbon_home_light.png`: yellow (`#ffd166`, 107 occurrences) and mint (`#06d6a0`, 69 occurrences) icons such as `Rotate`, `Ellipse`, `Dimension`, `Create`, and `Match Prop` drop below 1.5:1 contrast against `#e5e8ec` light grey.

6. **[HIGH] [R-32] Complete lack of keyboard navigation, Escape dismissal, and visible focus indicators.**
   - `ui/ribbon.js` has zero `keydown` listeners, so pressing `Escape` does not close open dropdowns, panel trays, or right-click context menus, and `Enter`/`Space` cannot activate `div`-based controls. `ui/style.css` defines zero `:focus-visible` outlines.

7. **[HIGH] [R-39] 209 interactive controls use `<div>` instead of `<button>`, 26 icon-only controls lack `aria-label`, all 236 SVGs lack `aria-hidden="true"`, viewport blocks zoom (`user-scalable=no`), and `prefers-reduced-motion` is missing.**
   - `ui/index.html` line 5 sets `user-scalable=no`; `cad-menu-item` (144), `panel-footer` (43), `cad-context-item` (15), `cad-combo` (3), `layer-combo` (1), `workspace-selector` (1), `cad-app-logo` (1), and `floating-ribbon-pill` (1) are `<div>` elements without native button semantics or ARIA roles.

8. **[HIGH] [R-35] Broken SVG text clipping and horizontal overflow on 1710px display.**
   - Verified in live screenshots:
     - `Output -> Export PDF` icon text overflows its box and renders as **"EXPO"** instead of "PDF".
     - `Annotate -> Dim Style` clips "ISO" to **"IS("**.
     - `Express Tools -> Count Blocks` clips `#12` to **`#1:`** and `Auto Number` clips `1,2,3` to **`1,2,`**.
     - `Home` tab overflows horizontally on a 1710px AutoCAD window, slicing `Utilities`, `Clipboard`, and `View` off the right edge (`Me...` cut mid-word) with no responsive compaction or scroll indicator.

9. **[HIGH] [R-02, R-36, R-38] `README.md` contains an em dash in the H1 title, outdated tab count ("7-Tab" while 10 tabs exist), and references non-existent features/installers.**
   - `README.md` line 1 uses an em dash (`—`); line 25 claims "7-Tab Navigation" (actually 10 tabs including 3D Tools and Express Tools); line 33 claims "Activity Insights" (not currently in the Collaborate tab); line 68 references `./MacRibbon-Installer` binary.

10. **[HIGH] [R-33] `scripts/bundle_html.py` patches `ui/index.html` via regex string replacement, duplicating 930 lines of CSS and 650 lines of JS inline.**
    - `ui/index.html` does not link `style.css` or `ribbon.js` directly; instead `bundle_html.py` regex-strips and injects CSS/JS into `index.html`, creating maintenance drift risks. (Because `RibbonViewController.mm` passes `baseURL: _resourcesURL`, linking `style.css` and `ribbon.js` cleanly or building cleanly from templates without regex patching avoids fragile string replacement.)

## MEDIUM Priority (Purpose-Gate Violations / "AI-Generated" Visual Tells)

11. **[MEDIUM] [R-04] Apple Color Emojis and generic AI icons used as CAD toolbar chrome.**
    - `Home -> Layers` quick-action row uses 7 glossy Apple Color Emojis (`💡 👁️ ❄️ 🔒 🎯 🎨 🔓`) directly inside a CAD ribbon.
    - `Collaborate -> Assist` uses a generic yellow 5-point star (`★`).
    - `src/RibbonManager.mm` (line 546) labels the floating switch button **`⚡️ Windows Ribbon`** with a lightning emoji.
    - `View -> Cmd Line` uses a fake terminal prompt box (`>_`), and `Home -> Layer Props` / `View -> Layer Props` use a 3-color neon diamond stack clipart icon.

12. **[MEDIUM] [R-04, R-01] Unmistakable AI "Coolors.co neon clipart" icon style instead of authentic Autodesk CAD technical drafting icons.**
    - All 236 SVGs spray the exact 4-color AI default neon palette (`#00b4d8` cyan x152, `#ffd166` yellow x107, `#06d6a0` mint x69, `#ef476f` hot pink x58) with generic geometric placeholders:
      - `Trim` and `Erase` are nearly identical neon-pink `X` marks (real AutoCAD Trim is scissors cutting a line).
      - `Offset` looks like a Wi-Fi symbol; `Match Prop` is a plain yellow stick instead of a paintbrush.
      - `View -> Visual Styles` uses 6 flat colored triangles instead of wireframe/shaded 3D cube previews.
      - `Manage -> Options` is an empty yellow circle, `Units` is an empty blue rectangle, `Insert -> Base Point` is a pink dot, `Adjust` is an empty yellow circle.
      - Dropdown menu items (`Circle`, `Arc`, `Array`, `Dimension`, `Measure`, `Visual Styles`, `3D Views`) have zero miniature technical icons.
      - `Properties` panel combos (`ByLayer` / `ByLayer` / `--- ByLayer`) lack distinguishing Color, Lineweight, and Linetype icons.
    - **Fix direction:** Replace with a cohesive, theme-adaptive Autodesk technical icon system (`currentColor` crisp geometry + subtle Autodesk blue `#4db8ff`/`#0070c0` accent + restrained warm amber only for handles/nodes), matching AutoCAD 2027's native right-hand Inspector chrome.

13. **[MEDIUM] [R-01, R-09, R-13] Top-right `Palettes` and `Mac Toolbar` controls and classic-mode floating button look like glowing web-app pill badges.**
    - `ui/style.css` lines 228-243 style `Palettes` and `Mac Toolbar` with translucent blue fills (`rgba(0, 150, 215, 0.14)`) and cyan borders (`rgba(0, 150, 215, 0.38)`), and `.floating-ribbon-pill:hover` (line 821) adds a blue glow shadow (`0 4px 12px rgba(0, 162, 255, 0.35)`), clashing with AutoCAD's matte flat native macOS/Windows toolbar chrome.

14. **[MEDIUM] [R-12] Excessive drop shadows on menus, trays, tooltips, and ribbon bar.**
    - `ui/style.css` uses heavy `0 8px 24px rgba(0,0,0,0.75)` and `0 10px 24px rgba(0,0,0,0.75)` web-modal shadows instead of crisp, tight native CAD elevation (`1px` border + subtle `0 3px 8px rgba(0,0,0,0.35)`).
